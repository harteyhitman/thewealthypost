# Supabase Setup Guide

To replace the NestJS backend with Supabase, follow these steps:

## 1. Create Tables

Run the following SQL in your Supabase SQL Editor:

### Posts Table

```sql
-- Create posts table
CREATE TABLE public.posts (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  slug TEXT UNIQUE NOT NULL,
  title TEXT NOT NULL,
  excerpt TEXT NOT NULL,
  content TEXT NOT NULL,
  image TEXT,
  author TEXT DEFAULT 'The Wealthy Post Team',
  date DATE DEFAULT CURRENT_DATE,
  tags TEXT[],
  category TEXT,
  published BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Enable Row Level Security (RLS)
ALTER TABLE public.posts ENABLE ROW LEVEL SECURITY;

-- Create policy to allow public to read published posts
CREATE POLICY "Allow public read-only access to published posts"
  ON public.posts FOR SELECT
  USING (published = true);

-- Create policy to allow authenticated users (admins) to manage all posts
CREATE POLICY "Allow authenticated users to manage all posts"
  ON public.posts FOR ALL
  TO authenticated
  USING (true)
  WITH CHECK (true);
```

## 2. Storage Setup

1. Go to **Storage** in your Supabase Dashboard.
2. Create a new bucket named `blog-posts`.
3. Set the bucket to **Public** (or configure appropriate RLS policies).

## 3. Authentication

Supabase Auth will replace the custom admin authentication.
1. Go to **Authentication** -> **Users**.
2. Add a new user (the admin email).
3. The frontend will now use Supabase Auth for login.

## 4. Environment Variables

Update your `.env.local` in `thewealthypost`:

```env
NEXT_PUBLIC_SUPABASE_URL=your-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```
